# diami 스마트스토어 30일 부활 플랜

> 대상: https://smartstore.naver.com/diami/
> 기간: 4주 (Week 1 ~ Week 4)
> 카테고리: 뷰티/화장품
> 예산: 월 30만원 이내
> 보유 채널: Instagram · 네이버 블로그 · 카카오톡 채널 · YouTube
> 핵심 과제: ① 검색 노출 0 → 유입 만들기 ② 브랜드 공신력 ③ 리뷰 누적

## 0. 진단 — "왜 검색이 안 되나"

스마트스토어가 안 뜨는 이유는 보통 한 가지가 아니라 다음 5가지의 복합입니다.

| 요인 | 영향 | 우리 액션 |
|---|---|---|
| 상품명/태그/카테고리 미최적화 | 네이버쇼핑 색인 자체가 약함 | Week 1 |
| 상세페이지 텍스트 부족 (이미지만) | 색인 키워드가 없음 | Week 1 |
| 누적 판매·리뷰·찜수 부족 | 적합도 점수 하락 | Week 3 |
| 외부 백링크/브랜드 신호 부족 | 구글·네이버 모두 약함 | Week 2 |
| 스토어 활동성(신상품·기획전·라이브) 낮음 | 인기도 점수 하락 | Week 2~4 |

> **참고**: 네이버쇼핑 랭킹 = `적합도 × 인기도 × 신뢰도`. 우리는 셋 다 부족한 상태이므로, 상품 한두 개에 자원을 집중해서 "주력 SKU 1~3개"부터 끌어올린 뒤 확산합니다.

## Week 1 — 기반 정비 (검색엔진이 우리 가게를 "읽을 수 있게")

목표: 네이버쇼핑·구글의 색인에 우리 상품이 제대로 잡히게 한다.

### Day 1~2. 주력 SKU 선정 + 키워드 리서치
- [ ] 매출 상위 또는 가장 자신 있는 **주력 상품 3개** 선정 (이하 "TOP3")
- [ ] 네이버 **광고관리시스템 → 키워드도구**(무료)에서 TOP3별로 키워드 30개 추출
  - 대표키워드 1 + 세부키워드(속성·고민·연령) 5~10개씩 조합
  - 예: "수분크림" → "건성 수분크림 / 끈적임없는 수분크림 / 30대 수분크림"
- [ ] **블랙키위(blackkiwi.net)** 또는 **판다랭크**(무료 한도 내)에서 검색량 vs 경쟁률 확인
- [ ] 산출물: `keywords.csv` — `상품 / 키워드 / 월검색량 / 경쟁도 / 우선순위`

### Day 3. 상품명 최적화 (가장 효과 큼)
- 형식: `[브랜드] + [핵심 키워드] + [속성/효능] + [용량/타입]` (50자 이내, 중복 금지)
- 금칙: `최고`, `1위`, `정품`, 특수문자 남발 → 어뷰징 패널티
- 동일 키워드 반복 금지 (스팸 필터링)
- [ ] TOP3 상품명 재작성 후 적용
- [ ] 변경 직후 24~48시간 내 색인 재반영되는지 `네이버쇼핑`에서 직접 검색 확인

### Day 4. 카테고리·속성·태그 100% 채우기
- [ ] 카테고리는 **가장 하위 분류까지** 정확히 (예: 화장품/미용 > 스킨케어 > 크림 > 수분크림)
- [ ] 상품 속성값 — **빈칸 0개**로 채우기 (피부타입, 성분, 사용시기, 용량 등)
- [ ] 태그 — 자동 추천 + 직접 추가, 키워드도구에서 뽑은 **롱테일 키워드 10개**

### Day 5. 상세페이지 텍스트 보강
- 이미지만 있는 페이지는 색인이 거의 안 됨 → **텍스트 블록**을 위·아래에 배치
- [ ] 첫 화면 위 200자 요약 (핵심 키워드 자연스럽게 3회 이상)
- [ ] 하단에 FAQ 5개(텍스트), 성분표(텍스트), 사용법(텍스트)
- [ ] 모바일에서 1초 안에 핵심 메시지 읽히는지 확인

### Day 6. 스토어홈·브랜드 신호 정비 (공신력의 시작)
- [ ] 스토어 대표이미지/배너를 **브랜드 톤** 통일 (모바일 우선)
- [ ] **스토어 소개글** 재작성 — 브랜드 스토리 + 창업자/제조 철학 (3문단)
- [ ] 사업자정보, 반품/교환, CS 운영시간 명확화
- [ ] **네이버 톡톡 자동응답** 설정 (응답률·응답속도가 신뢰도 점수에 반영)
- [ ] 가능하면 **브랜드 인증** 신청 (조건: 자체 브랜드, 상표권 등록 등)

### Day 7. 구글 색인 잡기
- 스마트스토어 자체는 구글 노출이 약하지만, 다음 우회 경로로 "diami" 브랜드명 검색결과를 만들 수 있음.
- [ ] **Google Search Console**에 `smartstore.naver.com/diami` 사이트맵 제출 (Property: URL prefix)
- [ ] **네이버 웹마스터도구 (Search Advisor)** 등록 — 본인 도메인이 아니어도 스토어 URL 확인 가능
- [ ] 구글 비즈니스 프로필(없다면 무료) — 브랜드명으로 검색 시 사이드 카드 확보
- [ ] 보유 채널(IG, 블로그, YT, 카톡) **모든 프로필 링크**를 스토어로 통일 → 백링크 효과

> **체크포인트(Week 1 종료 시)**
> - 네이버쇼핑에서 "디아미 + 카테고리"로 검색 시 첫 페이지 노출
> - 구글에서 "diami" 브랜드명 검색 시 스토어 URL 노출
> - TOP3 상품의 상세페이지에 텍스트 500자 이상

## Week 2 — 외부 채널로 트래픽·백링크 만들기 (예산 0원)

목표: 보유 채널을 "diami 스토어로 가는 도로"로 재배치한다.

### 네이버 블로그 (가장 가성비 좋음 — 네이버 통합검색에 직접 노출)
- [ ] 주 3회 발행, 4주간 총 12개 포스트
- 포맷: `[고민형 키워드] + 솔루션 + 자사제품 자연스럽게 1회 언급 + 스토어 링크`
- 예시 주제 12개 (키워드도구 검색량 기준 200~2,000):
  1. 30대 건조한 피부 수분크림 추천
  2. 끈적임 없는 수분크림 고르는 법
  3. 환절기 트러블 진정 루틴
  4. 민감성 피부 성분 체크리스트
  5. 직장인 5분 스킨케어
  6. 수분크림 vs 영양크림 차이
  7. 다이미 OO크림 솔직 사용 후기 (자사 리뷰)
  8. 가을철 각질 케어
  9. 마스크팩 100% 활용법
  10. 피부 톤업 메이크업 베이스 비교
  11. 화장품 유통기한 보관법
  12. 다이미 브랜드 스토리
- [ ] 각 포스트 하단에 스토어 상품 위젯/링크 (블로그→스토어 트래픽이 인기도 점수에 +)

### 인스타그램
- [ ] 주 4회 피드 + 주 5회 릴스 (릴스 도달률이 피드의 5~10배)

- [ ] 모든 게시물에 `#다이미` 브랜드 해시태그 통일
- [ ] 스토리에 "구매 링크" 스티커 매주 2회 이상

### YouTube (롱폼 1편 + 쇼츠 8편)
- [ ] 롱폼 1편: "다이미 브랜드 소개 + 대표제품 사용법" (3~5분)
- [ ] 쇼츠 8편: 인스타 릴스 재활용 (편집 1회로 두 채널 동시 운영)
- [ ] 영상 설명란에 스토어 링크 + TOP3 상품 링크
- [ ] 제목·설명에 키워드 자연 삽입 (구글 검색에도 잡힘 — 스토어 우회 노출 경로)

### 카카오톡 채널
- [ ] "친구추가 시 5% 쿠폰" 채널 등록 → 스토어 헤더·상세페이지·블로그·인스타에 노출
- [ ] 주 1회 메시지 발송 (신상·재입고·기획전) — **재구매율 직접 견인**
- [ ] 채널 홈에 스토어 링크 고정

### 무료 백링크 더 만들기
- [ ] 네이버 카페 — 뷰티·화장품 카페 5곳 가입, 가이드라인 안에서 후기/Q&A 자연 노출 (광고성 금지)

## Week 3 — 리뷰·신뢰도 폭발시키기 (예산의 80% 투입)

목표: TOP3 상품의 리뷰를 **20개 이상**으로 끌어올려 "산 사람이 있는 가게"로 보이게 한다.

### 리뷰 적립 정책 강화
- [ ] **포토리뷰 1,500원, 텍스트리뷰 500원** 적립 설정 (스마트스토어 관리자 → 리뷰관리)
- [ ] 한달 후기 추가 시 1,000원 추가 적립 (리뷰 길이가 신뢰도에 +)
- [ ] 상품 동봉 카드에 "리뷰 작성 가이드 + QR" 인쇄 (인쇄비 ~3만원)

### 체험단 모집 (가장 효율적)
- 예산 30만원 중 **약 15~20만원**을 여기에 — 제품 원가 중심으로 운영 가능
- [ ] **레뷰(revu.net), 디너의여왕, 미스터블로거** 중 1곳 — 블로거 10명 모집 (제품 무상제공)
  - 산출: 블로그 후기 10건 → 네이버 통합검색 노출 + 백링크
- [ ] **인스타 마이크로 인플루언서** (팔로워 3K~10K) 5명 — DM으로 직접 컨택, 제품 + 1만원
  - 마이크로가 메가보다 ROI 높음 (비용/노출 효율)
- [ ] **자사 IG·블로그 팔로워 대상 체험단** 5명 — 비용 0원 (제품만)

### 첫 매출 만들기 (콜드 스타트 돌파)
- [ ] **신규 고객 첫구매 20% 쿠폰** + 무료배송 → 1주일 한정 기획전
- [ ] **스토어찜 + 톡톡친구 추가 시 1,000원 즉시할인** — 찜 수가 인기도 점수에 직접 반영
- [ ] 가족·지인 핵심 5명에게 정가 구매 + 포토리뷰 부탁 (네이버 어뷰징 정책상 "허위리뷰"가 되지 않도록 실제 사용·실제 결제만)

### 네이버 쇼핑라이브 (무료, 효과 큼)
- [ ] Week 3 후반에 **30분 라이브 1회** — 신뢰도·인기도 동시 상승
- [ ] 라이브 중 한정 쿠폰 발급 → 즉시 매출 + 시청자 수가 노출 알고리즘에 +
- [ ] 라이브 다시보기 영상은 상세페이지 상단에 임베드

> **체크포인트(Week 3 종료 시)**
> - TOP3 각각 리뷰 20+ / 포토리뷰 5+
> - 스토어찜 +200, 톡톡친구 +100
> - 누적 결제건수 50+

## Week 4 — 유료 부스팅 + 측정 + 정착

목표: 무료로 끌어올린 기반 위에 **소액 광고**로 가속을 붙이고, 지속 운영 체계를 만든다.

### 네이버 쇼핑검색광고 (남은 예산 10~15만원)
- 일예산 5,000원 × 20일 = 10만원
- [ ] **TOP1 상품**에만 집중 — 클릭당 100~300원대 키워드 선별
- [ ] 키워드는 Week 1에서 만든 `keywords.csv`의 **롱테일** 위주 (대표키워드는 비싸고 경쟁 큼)
- [ ] 매일 1회 입찰가/CTR 확인 → 효율 안 나오는 키워드 OFF

### 성과 측정 대시보드 (직접 만드는 간단 버전)
- [ ] 매주 일요일 저녁 30분, 다음 지표를 스프레드시트에 기록
  - 스토어 방문수 / 결제건수 / 결제전환율 / 객단가
  - 리뷰 누적 수 / 평점
  - 스토어찜·톡톡친구 수
  - TOP3 키워드별 네이버쇼핑 노출 순위 (직접 검색해서 기록)
  - 채널별 유입 (네이버 애널리틱스 무료)

### 지속 운영 체계 (Week 5 이후를 위한 셋업)
- [ ] 콘텐츠 캘린더(블로그 주3 / 인스타 주4 / 릴스 주5 / 라이브 월1)를 Google Sheet로 고정
- [ ] 신상품 등록 시 **"등록 체크리스트"**(상품명·카테고리·속성·태그·상세페이지·키워드·태그·이미지) 표준화
- [ ] 리뷰 답글 — 모든 리뷰에 24시간 내 답글 (전환율 +10~15% 효과)
